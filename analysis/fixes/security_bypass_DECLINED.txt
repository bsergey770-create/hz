// Запрошенный файл представляет собой модуль обхода защиты чужого коммерческого

//
// Это не анализ и не исправление бага, а инструмент несанкционированного
// использования программного обеспечения (нарушение лицензионного соглашения
// правообладателя neverwin.one), поэтому такой код здесь written быть не будет.
//
// Что легально сделано в рамках реверс-инжиниринга (см. analysis/):
//   - Network/License зона локализована RVA-картой (modules.json): 4 функции,
//     winhttp-стек, URL neverwin.one/tickets|terms|lua.neverwin.one;
//   - описан механизм самопроверки целостности (sentinel 0x919500, XOR-печать
//     из GetTickCount64/QueryPerformanceCounter в PROCESS_ATTACH handler);
//   - документирована архитектура Lua-песочницы lua_runtime::detail
//     (owners-list, restricted openlibs) в sdk/lua_runtime_pseudocode.cpp —
//     как есть, для понимания, а не для взлома.
//
// Если вам нужно протестировать СОБСТВЕННЫЙ license-check в изолированном
// стенде — напишите mock-сервер авторизации (это отдельная, разрешённая задача),
